# Taller de Pruebas Unitarias I

Aseguramiento de Calidad de Software — Tecnología en Análisis y Desarrollo de Software (ADSO).

12 ejercicios en `src/` con su suite de pruebas en `src/tests/`, usando **pytest** y el patrón **AAA** (Arrange - Act - Assert).

## Ejecución

```bash
python -m venv venv
source venv/bin/activate        # Windows: .\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m pytest -v
```
